# Partner Onboarding Sequence

Goal: move partners from registration to stable Silver-level revenue.

Core principles:

- One email = one action.
- Reduce friction before pressure.
- Increase urgency in follow-ups.
- Keep copy short and outcome-focused.
- Activation starts when Partner App is installed and the first sale is closed.

Stage guide:

| Stage | Goal | Expected CTA | Review focus |
| --- | --- | --- | --- |
| registered | Confirm application and qualify intent | Upload documents / complete profile | Set expectations; low pressure |
| qualified | Complete verification and intro call | Book a call / continue verification | Push missing verification steps |
| approved | Start product usage | Set up NFR | Explain why setup enables client work |
| nfr-installed | Complete training | Start/complete training | Link training to leads, commission, Kickstart |
| training-completed | Install Partner App | Install Partner App / Get leads via Partner App | Make app install the clear activation step |
| partner-app-installed | Convert activation into first revenue | Start receiving leads / close first deal | Move from setup to action with leads |
| first-sale | Build consistency | Get more leads / close next deal | Reinforce momentum after first win |
| second-sale | Reach Silver target | Work with leads / close next deal | Push toward deal count and revenue target |
| silver-prequalified | Finalize Silver status | Book a call | Confirm requirements and next admin step |
| rejected | Explain rejection clearly | None / contact support if appropriate | Be respectful, concise, and clear |

Timing intent:

- Next step / immediately: clear next action, low pressure.
- Follow-up 1: reminder; reduce friction.
- Follow-up 2: stronger value or urgency.
- Last call: clear consequence, deadline, or final chance.
