# Email Review Rules

Evaluate the email text as part of a partner onboarding sequence.

Do not analyze:

- HTML structure
- CSS
- visual layout
- rendering quality
- accessibility
- template implementation details

Focus on:

- Subject line clarity: the recipient should immediately understand why the email matters.
- Preheader support: the preheader should add useful context and not repeat the subject.
- Message focus: the email should have one primary goal and avoid competing asks.
- CTA clarity: the main call to action should be specific, visible, and aligned with the email goal.
- Timing relevance: the message should make sense for its send timing and onboarding stage.
- Language consistency: the email should match the declared language and avoid mixed-language fragments.
- Readability: copy should be concise, scannable, and easy to act on.
- Partner onboarding fit: recommendations should consider partner activation, training, app installation, and first-sale progression.

Prefer practical recommendations that a marketer or partner manager can apply directly.
